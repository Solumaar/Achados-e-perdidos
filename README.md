## Sobre o projeto

Quem nunca perdeu algum objeto na escola ou na faculdade e precisou procurar por todos os lugares?

Pensando nessa situação, surgiu a proposta do **Achados e Perdidos — IFPE**: uma plataforma web que busca facilitar a comunicação entre pessoas que perderam objetos e aquelas que encontraram algum item no campus.

A ideia é reunir essas informações em um único ambiente, permitindo que estudantes, professores e servidores consultem os objetos cadastrados de maneira simples e intuitiva.

Mais do que uma página informativa, o projeto é uma oportunidade de aplicar conhecimentos de desenvolvimento web na construção de uma solução para uma necessidade do cotidiano acadêmico.

## O que estamos desenvolvendo

A proposta é construir uma plataforma com organização visual e navegação intuitiva, contemplando:

- **Consulta de objetos:** visualização dos itens cadastrados na plataforma.
- **Pesquisa:** localização de objetos por nome ou outras características.
- **Categorias e filtros:** organização dos itens para facilitar a consulta.
- **Cadastro de objetos:** espaço destinado ao registro de itens encontrados.
- **Detalhes dos itens:** informações sobre descrição, localização e data.
- **Acesso de usuários:** estrutura prevista para cadastro e identificação dos usuários.

Essas funcionalidades representam o escopo pretendido e serão disponibilizadas conforme forem implementadas.

## Identidade visual

A interface foi pensada para combinar simplicidade, acessibilidade e identidade institucional.

A escolha do verde como cor predominante faz referência à identidade visual do IFPE, enquanto os tons neutros ajudam a manter a leitura agradável e a organização das informações.

Entre as decisões de design estão:

- Paleta de cores baseada em verde e tons neutros.
- Tipografia de fácil leitura.
- Navegação objetiva e intuitiva.
- Layout pensado para diferentes tamanhos de tela.

## Tecnologias

As tecnologias utilizadas nesta etapa do projeto são:

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação do conteúdo e dos componentes da página. |
| CSS5 | Estilização, identidade visual e organização da interface. |

O projeto poderá incorporar outras tecnologias conforme suas funcionalidades evoluírem.


## Aprendizados

O desenvolvimento deste projeto permite trabalhar conhecimentos importantes para a formação em desenvolvimento Front-end, especialmente:

- Estruturação semântica com HTML.
- Estilização e organização visual com CSS.
- Utilização de classes e seletores.
- Organização de arquivos e diretórios.
- Princípios de UI (User Interface) e UX (User Experience).
- Acessibilidade e responsividade.

Também representa uma oportunidade de desenvolver habilidades de planejamento, resolução de problemas e organização de código.

## Próximos passos

O projeto pode evoluir com a implementação de novas funcionalidades, como:

- Sistema de cadastro e autenticação.
- Cadastro e gerenciamento de objetos.
- Pesquisa dinâmica e filtros funcionais.
- Visualização individual dos objetos.
- Integração com banco de dados.
- Painel administrativo.

## Sobre o desenvolvimento

Este projeto faz parte de uma experiência acadêmica de aprendizagem e desenvolvimento web.

A proposta é construir, experimentar, aprimorar e documentar cada etapa, buscando transformar conhecimentos teóricos em uma aplicação prática.

**Projeto acadêmico independente, sem vínculo oficial com o Instituto Federal de Pernambuco (IFPE).**
